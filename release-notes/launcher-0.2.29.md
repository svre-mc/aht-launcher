
### Repair and installation reliability

- Repair now restores damaged local launcher identity and an already-consented Phoenix installation, and escalates to full file recovery in the same attempt when needed.
- Repair reports missing launch prerequisites instead of reporting success while Play remains blocked.
- Install and Repair use one selected modpack release throughout download, runtime preparation and verification, even when a newer release is published during the operation.
- The developer publisher verifies complete public artifacts before switching the release feed, rejects conflicting versioned uploads, and coordinates storage checks with other publishers.

Existing player settings and saved worlds are preserved. This release updates the launcher only; it does not publish new modpack content.
