# A Hard Time Launcher 0.2.33

- Play now opens Minecraft account setup when the selected Java Edition profile is missing and continues automatically after selection or sign-in. CurseForge app login may be separate from the Minecraft Launcher used by AHT.
- Repair restores missing installation metadata and damaged files directly, and finishes Minecraft account setup before reporting completion.
- Windows permission failures can request administrator approval to restore access to the affected repair folder. Declining leaves Repair incomplete. Network failures offer a clear retry action.
- Improved Play and Repair error reports while preserving player data, protected-file checks and Phoenix Anti-cheat.
