Phoenix Anti-cheat

Phoenix Anti-cheat is a separate, optional-install Windows component required to
join A Hard Time servers. The launcher starts it only after the player clicks
Play. It is not embedded in the launcher installer and it does not add a Windows
service, startup entry, kernel driver, tray process, or background updater.
It does not install a service, does not run at system startup, and does not use a kernel driver.

The helper uses read-only access for one matching A Hard Time game session. It
does not send memory contents, absolute paths, personal documents, or unrelated
process lists. Confirmed flags are signed and submitted through the authenticated
launcher session for the restricted developer Sus view. The temporary signing
and local-session keys stay in memory and are never written into the game proof
file or player logs.

It requests query/read access only; it does not inject code, modify game memory,
install a driver, or alter antivirus settings. It exits with the game. If the
game has not started, it exits when the launcher closes (or after 30 minutes as a
final safety limit). Client protection complements server-authoritative checks;
no software running on a user-controlled computer can promise universal proof.
